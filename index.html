💡 Why this Architecture in Google Classroom?

  • Priority Queue: Grades submissions by priority (Special extensions, urgency, or strict timestamps).
  • Stack: Instant \(O(1)\) Undo/Redo for teachers when modifying grades or rubrics.
  • Linked List / Trees: Dynamically adds announcements and threaded replies without array resizing.
  • Hash Map & Trie: Instant \(O(1)\) student profile lookup and prefix search across thousands of assignments.

function insert(submission) {
  heap.push(submission);

// Extract Next to Grade

  const top = heap[0];
  heap[0] = heap.pop();
  sinkDown(0); // O(log N)
  return top;
}
